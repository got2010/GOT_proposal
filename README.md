# 映像プロポーザル情報

官公需情報ポータルサイト(中小企業庁)の検索APIから、西日本・東海の映像・動画・撮影に関する公告を毎朝7時(日本時間)に集めて、一覧ページに表示します。

## 設置手順

1. GitHubで新しいリポジトリを作成します(Publicで作成してください)。
2. このフォルダの中身をすべてリポジトリにアップロードします。`.github` フォルダも忘れずに含めてください。
3. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にします。
4. **Actions** タブを開き、左の `daily-collect` を選んで **Run workflow** を押します(初回の手動実行)。
5. 1〜2分で完了します。**Settings → Pages** に表示されるURLが、一覧ページのアドレスです。

以降は毎朝7時に自動で更新されます。

## 収集条件を変える

`config.json` を編集します。

| 項目 | 内容 |
| --- | --- |
| `lg_codes` | 対象の都道府県コード。初期値は愛知・岐阜・三重、近畿、中国、四国、九州、沖縄 |
| `video_keywords` | 映像関連と判定するキーワード |
| `proposal_words` | プロポーザル系と判定する語(件名・公告文に含まれるもの) |
| `lookback_days` | 何日前までの公告を取得するか(初期値90日) |

都道府県コードは JIS X0401 の2桁です(例:静岡は `22`、福井は `18`)。

## 仕組みと注意点

- 取得元は官公需情報ポータルサイトの検索APIです。仕様: https://www.kkj.go.jp/doc/ja/api_guide.pdf
- 同ポータルは、発注機関のHPに掲載された入札情報を、公開の約1日後にデータベースへ登録します。自治体HPにしか載らないプロポーザルは、このAPIでは拾えません。
- 締切日は公告文から推定した目安です。誤りや抜けがあるため、応募前に必ず原文を確認してください。
- 取得結果は `docs/data/tenders.json` に蓄積され、初めて見つかった日が「新着」の判定に使われます。
- GitHubは、リポジトリに60日間動きがないと定期実行を止めることがあります。止まった場合は、Actionsタブから再開してください。
- 取得に失敗した場合はActionsが失敗扱いになり、GitHubから通知メールが届きます。

## ファイル構成

```
collect.py                      収集スクリプト
config.json                     収集条件
.github/workflows/daily.yml     毎朝の自動実行と公開
docs/index.html                 一覧ページ
docs/data/tenders.json          収集結果(自動更新)
```
